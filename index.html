ЕСЕПКЕ АРНАЛҒАН ҚЫСҚАША ЖАУАПТАР

Бақылау
сұрақтары.

20 сұрақтың жауаптары. Толық нұсқа мен есепке арналған скриншот тізімі README файлында.

01 Object Storage дегеніміз не?

Object Storage — деректерді объектілер түрінде сақтайтын, API арқылы файлдарды жүктеуге және алуға арналған бұлттық қызмет.

02 Bucket дегеніміз не?

Bucket — Object Storage ішіндегі объектілерді сақтайтын атауы бірегей контейнер.

03 Object дегеніміз не?

Object — Bucket ішінде сақталатын файл және оның метадеректері мен бірегей кілті.

04 Object Storage статикалық сайтқа неге қолайлы?

Дайын HTML, CSS, JavaScript және суреттерді серверді басқармай сақтап, HTTP арқылы таратады.

05 Неге динамикалық кодты іске қоспайды?

Object Storage файлдарды сақтап, береді, бірақ PHP, Python немесе Node.js бағдарламаларын орындамайды.

06 Статикалық және динамикалық сайттың айырмасы қандай?

Статикалық сайт алдын ала дайын файлдарды қайтарады; динамикалық сайт серверде сұранысқа қарай бет құрастырады.

07 index.html не үшін керек?

Ол сайттың негізгі құжаты; түбірлік адрес ашылғанда әдепкі бет ретінде беріледі.

08 error.html не үшін керек?

Сұралған объект табылмаған кезде көрсетілетін арнайы қате бетін анықтайды.

09 Website Endpoint дегеніміз не?

Endpoint — браузерден веб-сайтқа кіруге арналған, Bucket хостингі үшін берілетін мекенжай.

10 Public Read Access дегеніміз не?

Кез келген адам объектілерді оқи алады; жазу және жою құқығын көпшілікке ашпайды.

11 Қоғамдық оқуда қандай қауіпсіздік тәуекелі бар?

Жариялауға болмайтын файлдар да ашылып кетуі мүмкін. Құпияларды жүктемей, тек қажетті объектілерге оқу рұқсатын бер.

12 Object Durability дегеніміз не?

Durability — объектінің ұзақ уақыт сақталып, жоғалмай қалу ықтималдығын сипаттайтын көрсеткіш.

13 Durability неліктен маңызды?

Ол сақталған деректің жоғалу тәуекелін бағалауға және сақтау сенімділігі туралы шешім қабылдауға көмектеседі.

14 Storage Class дегеніміз не?

Storage Class — сақтау құны мен дерекке қол жеткізу сипаттарына әсер ететін сақтау класы.

15 Сирек қолданылатын файлға арзан класс таңдаудың пайдасы?

Қол жеткізу шарттары қолайлы болса, ұзақ сақталатын, сирек оқылатын деректердің құнын азайтады.

16 Object Storage пен виртуалды машина қалай ерекшеленеді?

Object Storage — файлдарды сақтау қызметі; виртуалды машина — операциялық жүйе мен бағдарламаларды іске қосатын есептеу ортасы.

17 CSS жүктелмеуінің ықтимал себебі қандай?

Файл жолы не атауы қате, объект жүктелмеген, рұқсат жабық немесе атаудың үлкен-кішілігі сәйкес емес болуы мүмкін.

18 Неге негізгі және қате беттер бөлек беріледі?

Хостингке табысты сұраныстың әдепкі құжаты мен қате сұранысының құжатын жеке тағайындау қажет.

19 Object Storage-дің статикалық сайтқа артықшылығы қандай?

Қарапайым орналастыру, серверді басқармау, файлдарды масштабты түрде тарату және шығынды оңтайландыру.

20 Сайт жұмысын қалай тексеруге болады?

Endpoint-ті ашып, негізгі бет, CSS, суреттер, JavaScript және жоқ мекенжайдағы error page нәтижесін тексер.
